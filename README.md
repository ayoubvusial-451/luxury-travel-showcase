# HRS CAR — Location de voiture

Site vitrine premium pour **HRS CAR كراء السيارات | Location de voiture**, agence locale à Oulad Teima, Maroc.

## Lancer le site

Aucune dépendance n'est nécessaire. Ouvrez `index.html` dans un navigateur ou servez le dossier avec n'importe quel serveur statique :

```bash
python3 -m http.server 8000
```

Puis visitez `http://localhost:8000`.

## Personnalisation

Les trois véhicules de démonstration sont regroupés dans `script.js`, dans le tableau `vehicles`. Vous pouvez y remplacer facilement les noms, images, prix, catégories et caractéristiques. Les URLs d'images actuelles sont des images temporaires de démonstration : remplacez-les par vos fichiers dans `images/` lorsque vous les fournirez.

Les formulaires et la réservation sont actuellement une expérience front-end de démonstration : aucun paiement ni numéro de téléphone n'a été inventé.
